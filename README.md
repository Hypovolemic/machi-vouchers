# Machi Vouchers · まちバウチャー

Local premium shopping vouchers and a shopping-street stamp rally on Sui.

A chamber of commerce issues vouchers as Sui Closed-Loop Tokens that only work at registered shops and can't be sent to anyone else. The city funds the premium. When a resident pays, one transaction spends the voucher and pays the shop from the program vault. Staff add a stamp with one tap, and five different small shops earn a ¥500 bonus.

Built solo for ETHGlobal Tokyo 2026 (25–27 Sep 2026). Work in progress: this README grows with the build.
